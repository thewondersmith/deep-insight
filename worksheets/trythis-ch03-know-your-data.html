Sort your recent data

ItemStructuredSemi-structuredUnstructuredDoesn't fit cleanly? Why?

Mark the column with an X. Structured = rows and columns with fixed rules. Semi-structured = tags and metadata, like JSON or API feeds. Unstructured = posts, imagery, audio, PDFs.

Bonus

Provenance spot check (Table 3.1)

Pick one random data point from your workflow and see if you can answer all three.

Provenance questionMy answer for this data pointCan I answer it?
Origin: where did this come from? (URL, timestamp, collection method)
Transformation: what happened to it? (cleaning, renaming, AI preprocessing)
Custody: who handled it? (tools, versions, models, human checkpoints)

If you can't fill in that last table, you don't have provenance, and you can't lean on analysis built from that data.
