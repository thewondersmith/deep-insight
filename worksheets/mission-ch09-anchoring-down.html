Prompts

Copy these into your AI tool, one step at a time

Open Google Colab, create a new notebook, and name it Domain History Analyzer. Remember the loop: prompt, read, explain, verify, run. You are generating your own code, not copying mine.

Step 1: Install your libraries
Write me a single line of Python that installs the requests and pandas libraries in Google Colab.
Good output: one line starting with ! then pip install and the two library names. Run it and wait.
Step 2: Import your libraries and create your domain list
Write me a Python cell for Colab that imports the requests, pandas, and time libraries and creates a list variable called domains containing five placeholder domain names. Remove the [] brackets from the domains: Kmsupdate2023[.]com, Windowsupdatesystem[.]org, kms-win11-update[.]net, Kalambur[.]net, ratiborus2023[.]com
Good output: no more than 8 lines, the word import 3 times, and the five domains below it.
Step 3: Build the lookup function
Write me a Python function called check_domain_history that takes a single domain name as input, queries the Internet Archive Wayback Machine CDX API to find the first time that domain was ever archived and the most recent time it was archived, and returns a dictionary containing the domain name, first seen date formatted as YYYY-MM-DD, last seen date formatted as YYYY-MM-DD, the HTTP status code from the first capture, and a flag field that says NO HISTORY if the domain has never been archived, RECENTLY REGISTERED if the first capture was after 2022, and No anomalies detected otherwise. Include error handling so the function returns an error message instead of crashing if something goes wrong.
Good output: the Wayback Machine URL in the code, four fields in the return statement, and a try and except block.
Step 4: Run it against your list
Write me a Python cell that loops through a list called domains, calls check_domain_history for each one, waits one second between each call, collects all the results in a list called results, converts that list to a pandas DataFrame called df, and prints the DataFrame.
Good output: includes time.sleep so you don't hammer the API and get your IP blocked.
Step 5: Visualize and export your results
Write me a Python cell that takes a pandas DataFrame called df and creates a horizontal bar chart using matplotlib showing each domain on the y-axis and the number of total captures on the x-axis. Color the bars red if the flag field contains NO HISTORY or RECENTLY REGISTERED and green otherwise. Add a title that says Sandworm Group Domain History Analysis, label the axes, and save the chart as domain_history_chart.png.
Heads up: this one may throw an error. Use Colab's Explain Error button. Fixing it is part of the lesson.
